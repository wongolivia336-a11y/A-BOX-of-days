# 一盒日子 · A Box of Days

A small, hand-drawn chocolate calendar prototype. V5 presents the interactive app inside a responsive phone model with a Dynamic Island that follows date selection, wrapper progress, reveal, and mood saving. It builds on V4's illustrated wrapper peel and continuous chocolate-texture slider.

## Files

- `index.html`, `styles.css`, `app.js`, `assets/`: editable V5 web source.
- `A_Box_of_Days_Naive_V5_Preview.html`: self-contained offline preview with artwork embedded.
- `A_Box_of_Days_Naive_V4_Preview.html`: previous iteration, retained for comparison.

Open the V5 standalone preview in a browser, or serve this repository root to run the source version.
