# 一盒日子 · A Box of Days

A small, hand-drawn chocolate calendar prototype. This repository contains the V4 interaction polish: centered calendar chocolates, a multi-frame wrapper reveal, and a continuous chocolate-texture mood slider.

## Files

- `index.html`, `styles.css`, `app.js`, `assets/`: editable web source.
- `A_Box_of_Days_Naive_V4_Preview.html`: self-contained offline preview with artwork embedded.

Open the standalone preview in a browser, or serve this repository root to run the source version.
